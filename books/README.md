# Books

Drop finished ebooks here once ready:

- `.epub` — primary format for mobile e-reader apps (微信读书, Apple Books, etc.)
- self-contained `.html` — offline-readable fallback, no external assets, for cases where the live site isn't reliably reachable

Each book gets its own folder, e.g. `books/example-title/`, containing the `.epub`, the standalone `.html`, and a cover image.
